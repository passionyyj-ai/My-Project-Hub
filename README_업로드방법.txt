MY PROJECT HUB — 개발 결과 반영 버전

설치 파일
index.html, styles.css, app.js, workspace.js, result-import.js, self-update.js,
config.js, manifest.webmanifest 및 이 안내 파일을 현재 앱의 실행/호스팅 폴더에 함께 반영합니다.
기존 config.js 연결 설정은 유지하세요. self-update.js는 이전 배포 기능을 제거하기 위한 빈 호환 파일입니다.
이번 소스 변경은 실행 중인 사이트에 자동 배포되지 않습니다. 이 버전을 설치한 뒤 아래 기능을 사용할 수 있습니다.

개발 결과 한 번에 반영
1. 앱에서 반영할 프로젝트를 선택합니다.
2. '개발 결과 한 번에 반영' 버튼에서 .zip, .json 또는 .mph 파일을 선택합니다.
3. ZIP은 반영할 프로젝트와 산출물 목록을 보여 줍니다. 개발 결과 요약을 입력하고 '현재 프로젝트에 반영'을 누릅니다.
4. 원본 ZIP과 내부 파일은 문서 관리에 첨부되고, 입력한 요약은 개발 일지에 등록됩니다.
5. 동일한 ZIP은 파일 이름이 바뀌어도 같은 프로젝트에 중복 반영되지 않습니다.

ZIP으로 소스 파일을 가져와도 실행 중인 앱 코드를 교체하거나 배포하지 않습니다.
파일은 기존 My Project Hub의 프로젝트 저장 공간에 보관합니다. 추가 계정 연결이나 인증 토큰은 필요하지 않습니다.
소스만 있는 ZIP에서 완료된 작업이나 진행률을 추측하지 않습니다.
ZIP 루트(또는 하나의 상위 폴더)에 mph-update.json이 있으면 그 파일에 명시된 작업·단계·문서·일지 등을 함께 반영합니다.
mph-update.json은 기존 mph-update-v1 형식을 사용합니다. 파일 안의 소스나 README는 실행하거나 지시문으로 해석하지 않습니다.

예시 mph-update.json
{
  "schema": "mph-update-v1",
  "updateId": "result-20261007-01",
  "tasks": [{"title": "모바일 메뉴 구현", "done": true}],
  "phases": [{"name": "개발", "progress": 80}],
  "logs": [{"title": "개발 결과", "detail": "모바일 메뉴를 개선했습니다."}]
}

ZIP은 최대 20MB, 압축 해제 총 10MB, 파일당 2MB, 최대 128개 항목까지 지원합니다.
최신 Chrome 또는 Edge를 사용하세요. 파일 업로드에는 인터넷 연결이 필요합니다.
파일 업로드 실패 시 프로젝트 기록을 반영하지 않고 업로드한 임시 파일 삭제를 시도합니다.
프로젝트 저장 실패 시 미저장 상태를 표시하고 자동 재시도합니다.

기타 개선 기능
- 프로젝트별 자동 저장, 계정별 임시 저장, 충돌 확인
- 단계·작업·문서·기록 수정 및 모바일 전체 메뉴
- 작업 기한·우선순위·지연 표시, 검색·필터·정렬
- 첨부 파일을 포함한 전체 백업 및 새 프로젝트 복사본으로 복원
